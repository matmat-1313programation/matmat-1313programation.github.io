- script.js : menu mobile, thème clair/sombre et année automatique

MISE EN LIGNE SUR GITHUB PAGES
1. Décompresser l'archive.
2. Envoyer tous les fichiers directement à la racine du dépôt GitHub Pages.
3. Vérifier dans Settings > Pages que la publication utilise la branche voulue et le dossier / (root).
4. Attendre la publication puis ouvrir l'adresse GitHub Pages.

À PERSONNALISER AVANT PUBLICATION
- Remplacer les textes génériques par ton vrai parcours et tes informations.
- Ajouter tes vrais projets, captures d'écran et liens de démonstration.
- Ajouter tes cours (PDF, fiches) à la racine et créer leurs liens dans ressources.html.
- Ajouter une vraie illustration/avatar à la place du monogramme M si tu le souhaites.
- Compléter et vérifier les mentions légales selon ta situation.
- Vérifier les informations de contact et le lien GitHub.

IMPORTANT
Le site est statique : le lien e-mail ouvre un logiciel de messagerie. Aucun formulaire de contact serveur n'est configuré. Le thème clair/sombre mémorise le choix dans le navigateur.
